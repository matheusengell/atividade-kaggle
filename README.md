# 🚀 Atividade Prática: Machine Learning com Streamlit
**Disciplina:** Data Science  
**Entrega:** 27/02  
**Tecnologias:** Python, Streamlit, Scikit-Learn, Joblib

Este repositório contém dois projetos de Machine Learning desenvolvidos para a disciplina de Data Science. O objetivo é demonstrar o fluxo completo desde o treinamento do modelo até a disponibilização em uma interface interativa.

---

## 📂 Projetos Incluídos

### ⚽ 1. FIFA Player Rating Predictor (Dataset Livre)
Um modelo de **Regressão** que estima o *Overall Rating* de um jogador de futebol com base em seus atributos técnicos.
- **Modelo:** Random Forest Regressor
- **Entradas:** Pace, Shooting, Passing, Dribbling, Physic.
- **Saída:** Valor numérico do Rating (0-99).

### 🚢 2. Titanic Survival Predictor
Um modelo de **Classificação** que prevê a probabilidade de sobrevivência de um passageiro no desastre do Titanic.
- **Modelo:** Random Forest Classifier
- **Entradas:** Classe (1ª, 2ª ou 3ª), Sexo, Idade, Irmãos/Cônjuges a bordo e Tarifa.
- **Saída:** Status de Sobrevivência (Sobreviveu / Não Sobreviveu).
